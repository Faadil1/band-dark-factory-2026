# BAND → Codex End-to-End Technical Reality Trigger

Creating this pull request is the single initial human/project trigger.

After the pull-request event, the bounded probe must proceed without human steering:

1. Coordinator creates a BAND room and hands the ticket to Implementer.
2. Implementer receives the ticket through BAND.
3. Implementer runtime dispatches the bounded Codex task.
4. Codex returns a machine-readable patch through its official GitHub bot comment.
5. The safe GitHub Actions relay validates, commits, and pushes the exact patch.
6. Implementer records the resulting GitHub SHA back in BAND.
7. Reviewer receives the receipt and acknowledges the exact SHA.

No Pocketful product work is started by this probe.
